# 🎓 TutorBoard — Интерактивная доска для репетиторства

Полнофункциональная платформа для проведения онлайн-занятий и репетиторства в реальном времени со встроенной голосовой связью (WebRTC), совместным рисованием на доске и входом по коду комнаты.

---

## 🚀 Быстрый запуск на вашем ПК

### Шаг 1. Установка зависимостей
Распакуйте архив с проектом в удобную папку, откройте командную строку в этой папке и выполните:
```bash
npm install
```

### Шаг 2. Запуск сервера

**Вариант 1 (Быстрый запуск для разработки):**
```bash
npm run dev
```

**Вариант 2 (Рекомендуется для максимальной стабильности и скорости):**
```bash
npm run build
npm start
```

Откройте в браузере на основном ПК: **[http://localhost:3000](http://localhost:3000)**

## 🌐 Как открыть доступ для второго ПК / Ученика

### 1. Доступ через локальную сеть (один Wi-Fi / роутер)
Если второй компьютер подключен к тому же Wi-Fi:

1. **Разрешите входящие подключения в Windows (Брандмауэр):**
   Windows по умолчанию блокирует подключения к сторонним портам от других компьютеров.
   Откройте командную строку **от имени администратора** и выполните:
   ```cmd
   netsh advfirewall firewall add rule name="TutorBoard 3000" dir=in action=allow protocol=TCP localport=3000
   ```
2. Узнайте свой локальный IP-адрес:
   - В командной строке введите `ipconfig` и найдите строку `IPv4-адрес` (например, `192.168.1.45`).
3. На втором компьютере откройте браузер:
   ```
   http://192.168.1.45:3000
   ```

---

### 2. Доступ через Интернет (Ученик в любом месте) ⭐ Самый надежный способ

Для работы микрофона в браузерах требуется защищенный протокол **HTTPS**. Вы можете получить бесплатную безопасную ссылку за 10 секунд:

#### Способ А: Cloudflare Tunnel (Быстро и без паролей)
Не выключая сервер проекта, откройте **второе окно терминала** и выполните:
```bash
npx cloudflared tunnel --url http://localhost:3000
```
Вы получите готовую ссылку `https://xxxx.trycloudflare.com`, отправьте её ученику.

#### Способ Б: Ngrok
```bash
npx ngrok http 3000
```
Вы получите ссылку `https://xxxx.ngrok-free.app`.

#### Способ В: Localtunnel
```bash
npx localtunnel --port 3000
```
> ⚠️ **Важно для localtunnel:** При первом переходе по ссылке `*.loca.lt` браузер покажет страницу с кнопкой **"Click to Continue"** или запросит пароль туннеля (это ваш внешний IP, который можно посмотреть на [ipinfo.io/ip](https://ipinfo.io/ip)). Нажмите кнопку, и сайт сразу откроется.
